# Neo · iOS 27

Liquid Glass remix of the Neo companion. Web prototype + SwiftUI sketch.

- Netlify project: https://neo-ios27.netlify.app
- Dashboard: https://app.netlify.com/projects/neo-ios27

Link this GitHub repo to the Netlify site to publish the proto.

## Web
Open `index.html`. FR/EN in Settings.

Gestures: long-press the orb, swipe up / left / right.

## SwiftUI
Drop `swift/*.swift` into an iOS 18+/27 Xcode app named NeoIOS27.
